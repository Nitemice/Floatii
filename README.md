# Floatii
*A floating, always-on-top image window utility for Windows.*

## Features

- Always-on-top floating window  
- Click and drag to move the window  
- Automatically snaps to nearest screen edge when moved close  
- Scroll mouse wheel over window to adjust window opacity  
- Tray icon for changing image or quitting

### Custom Images

When opened, Floatii will randomly load one of 9 "Windows 3.1" wallpaper tile
patterns.  
You can load your own image using the “Change Image” option in the menu,
accessed from the tray icon or by right-clicking the window.  
With a custom image loaded, the window can be freely resized, and will stretch
the image to fit.
